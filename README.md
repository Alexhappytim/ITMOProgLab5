## Лабораторная 5
В варианте дан класс Dragon с набором полей, в том числе других классов. Нужно реализовать консольное приложение для работы с коллекцией PriorityQueue<Dragon>

В программе реализован паттерн Command, дополнительным заданием была команда undo

## Лабораторная 6
Необходимо разделить консольное приложение на 2 части, клиент и сервер. Запросы реализовать с помощью протокола UDP. Работу с коллекцией переписать на Stream API

## Лабораторная 7
Доработать ЛР 6 добавив работу с БД (PostgreSQL) и возможность регистрации/логина. Серверную часть приложения сделать многопоточной с применением конкретных классов (поэтому это может выглядить немного неуместно)

## Лабораторная 8
Заменить консольное клиентское приложение на GUI с помощью JavaFX
